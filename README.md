## MUSIC追加方法
`data/content.js` の `music` に追加します。

例:

```js
{
  title: "曲名",
  artist: "ALROD",
  youtubeId: "YouTube動画ID",
  url: "https://www.youtube.com/watch?v=..."
}
```

artistは次のいずれかにしてください。

- `ALROD`
- `CHROM`
- `VI-LAIN`

新しい曲を配列の一番上に追加すると、トップページの最新6件にも表示されます。
